Drone Security Analyst Agent

A prototype that analyses a docked drone's telemetry and video-frame descriptions, logs what it sees, raises security alerts, indexes every frame and answers follow-up questions.

This page shows saved results from real runs of the Python prototype. It does not run the Python code live. Video frames are simulated as text captions.

How it works

  
Frame and telemetry → perception (caption to objects) → context memory (visits, dwell time, earlier sightings) → rule engine (explainable alerts with recommended actions) → SQLite frame index → agent and summaries.
